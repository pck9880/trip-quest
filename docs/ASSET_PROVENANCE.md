## PWA icons

PWA icons are generated during the GitHub Actions deployment using the script in `.github/workflows/pages.yml`. They are simple generated color PNGs rather than bundled third-party icon artwork.

## UI icons

Most interface icons in `app-chrome.js` are inline SVG path definitions maintained as project source. They should be included in code review during legal due diligence like any other project-authored source.

## Removed legacy assets

Earlier cover iterations were removed from the v1.0.0 working tree to reduce ambiguity and repository clutter. Git history may still contain them.

## Sale representation

A source-code sale agreement should transfer only the seller's actual rights and separately identify third-party or unverified material. Public Git history, forks, or prior clones cannot be made retroactively exclusive by changing repository visibility.
